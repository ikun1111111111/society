ABOUT US

我们是谁

象罔，出自《庄子·天地》：黄帝丢了玄珠，让"知"去找、让"离朱"去找都找不到，最后无心而求的"象罔"找到了。我们借这个名字，是想提醒自己——最好的东西往往不是刷题刷出来的，是在动手折腾的过程中撞见的。

PORTFOLIO

作品背后，是人

我们不罗列技术栈，讲讲每个项目是谁做的、踩了什么坑。

Web 全栈 · TypeScript / Vue3 / Node.js运营中

校园二手交易平台

从需求分析、数据库设计到上线部署完整走了一遍生产流程，现在全校区的同学都在用。

背后的故事：上线第一周就崩过一次——有人挂了 300 张图把服务器打爆了。全组连夜加上了图片压缩和限流，这节课比任何教材都深刻。
人工智能 · Python / LLM / RAG迭代中

AI 校园问答助手

接进新生 QQ 群，自动回答报到、选课、社团等高频问题，核心检索模块已开源。

背后的故事：最初版本一本正经地胡说八道，后来引入 RAG 让每个回答可溯源，才敢真正放进新生群。错误率从 30% 降到了 5% 以下（占位）。
游戏开发 · TypeScript / Canvas已发布

像素风小游戏

48 小时 Game Jam 产物，零引擎依赖，纯手写游戏循环和碰撞检测，浏览器打开即玩。

背后的故事：交稿前 2 小时发现角色会掉出地图，三个人围着一台电脑排除了 40 分钟——凶手是一个没加判定的边界条件。
效率工具 · TypeScript / ECharts迭代中

课表可视化工具

一键导入教务系统课表，自动生成周视图与冲突检测，还能导出分享图。

背后的故事：作者自己就是"每学期手动对表排课排到崩溃"的人。工具做出来后，第一个用户是他室友，第二个用户是全社团。
